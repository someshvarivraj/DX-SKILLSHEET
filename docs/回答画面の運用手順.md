# 回答画面の運用手順（候補者のマイページで回答を集める）

2026-10-08 更新。設問マスタ・質問セット・候補者のマイページを使って、候補者から回答を集め、スキルシートを作るまでの手順。

候補者に送るのは「フォームのリンク」ではなく、**本人のマイページへのログインリンク**。マイページでは、アンケートへの回答（初回・更新の依頼）と、完成したスキルシートの確認ができる。Googleフォームで回答した人の取り込みも、これまでどおり併用できる。

## 全体の流れ

1. **設問を用意する** — 設問マスタで、聞く設問がそろっているか確認する（.gs を取り込むか、画面で追加・編集する）
2. **質問セットを用意する** — 聞く設問・必須・表示条件・締め切りを決め、「受付中」にする
3. **候補者を追加する** — 名前とメールアドレスを入れると、一人ずつマイページのログインアカウントができる
4. **ログインリンクを送る** — 「メールで送る」か「ログインリンクをコピー」して送る
5. **候補者が回答する** — マイページから回答画面を開き、途中保存しながら回答し、最後に提出する
6. **スキルシートができる** — 提出されると、取り込みのときと同じように AI がスキルシートを作る
7. **確認・確定・PDF** — これまでどおり、対象者一覧から確認して確定し、PDFを出力する

## 1. 設問を用意する（設問マスタ）

- 左メニュー「設問マスタ」
- 新しい年度のフォームがある場合は「Googleフォームのスクリプト（.gs）を取り込む」。確認画面を見てから取り込む
  - 番号は同じでも内容が変わった設問は「同じ設問 / 別の設問」を選ぶまで取り込めない
  - 取り込んでも「回答ファイルの取り込み先」は変わらない（変える場合はチェックを入れる）
- 画面で直す場合は、設問の右の鉛筆ボタン
  - 文言（日英）、説明、記入例、選択肢（1行に1つ）、「その他」、上限（例: JLPT総合点 0〜180）、グループ
  - 回答のある設問は削除できない。「非表示」か「別の設問に置き換える」を使う

## 2. 質問セットを用意する

- 設問マスタの質問セットの「編集」（または「設問を選ぶ・編集」）
- 上の欄で **受付の状態を「受付中」**、**回答の締め切り**を入れて「保存」
- 下の一覧で、聞く設問にチェック。必須、並び順、表示条件（例: 学歴レベルが「修士」のときだけ）を設定する
- 新しい年度は「新しい質問セット」→ 前年のセットを「コピー」して、変わった所だけ直すのが早い

## 3. 候補者を追加する

- 質問セットの画面の「候補者とマイページ」
- 1行に1人、`名前, メールアドレス` の形で入力 →「候補者を追加する」
- 追加した人には、マイページのログインアカウント（役割「技術者（本人）」）が作られる
- **既に Googleフォームで回答している人**（回答ファイルを取り込み済みの人）は、その回答が入った状態になる。本人は確認して提出するだけ
- 管理者・社員のアカウントで使っているメールアドレスは、候補者のログインには使えない

## 4. ログインリンクを送る

- 「メールで送る」: 候補者にマイページへのログインリンクつきのメールが届く（英語・日本語）
  - 初めての人には「マイページのご案内」、前に回答したことがある人には「情報の更新のお願い」が届く
  - メールの送信設定（SES）が本番になるまでは、届かない宛先がある。その場合は次の方法で
- 「ログインリンクをコピー」: 自分のメールやチャットで送る
- リンクは本人専用で、**30日間、何度でも開ける**。期限が切れたら、本人がログイン画面でメールアドレスを入れると新しいリンクが届く
- アンケートに回答できるのは、質問セットが「受付中」で、締め切り前のときだけ

## 5. 候補者が回答する

- ログインリンクを開くとマイページが表示される（英語。右上で日本語に切り替えられる）
- マイページの「入力を始める／続きを入力する」から回答画面を開く。スマートフォンでも回答できる
- 入力は自動で保存され、あとでマイページから続きを入力できる
- 長い文章の設問は「Write in full screen」で画面いっぱいに書ける
- 必須・上限などはその場で確認され、満たしていないと先に進めない
- 最後に確認画面 → 「Submit」→ 確認ダイアログで提出

## 6〜7. スキルシート

- 提出されると、候補者が「対象者一覧」に出る（または既存の人が更新される）
- スキルシートを確定すると、本人のマイページで「スキルシートを見る」から見られる（社内用の補足資料は見えない）
- 確定後は、本人がマイページから新しい経験（インターンシップ・プロジェクト）を追加して確認を依頼できる
- 初めての回答なら、AI がスキルシートを作る（MoraBot の進み具合が出る）。2回目以降は、変わった部分の確認になる
- 候補者の質問セットで聞いていない設問の項目（日本人候補者の JLPT など）は、PDF に出ない

## 回答を直してもらうとき

- 提出済みの人の「更新を依頼する」→ 回答が入った状態で、もう一度回答できるようになる
- 「メールで送る」で本人に知らせる（「情報の更新のお願い」のメールが届く）。本人はマイページから確認・更新して提出する

## 試験運用（現在の候補者 10人）

1. 「2026 インド新卒」（または今年の質問セット）を「受付中」にし、締め切りを入れる
2. 10人を「名前, メールアドレス」で追加する
   - 既に Googleフォームで回答した6人は、回答入りの状態になる → 確認して提出してもらう
   - まだの4人は空の状態 → 回答してもらう
3. ログインリンクを送る（メール、またはコピー）
4. 「候補者とマイページ」で提出状況（未回答 / 回答中 / 提出済み）を確認
5. 提出された人のスキルシートを、これまでどおり確認・確定する
6. 気づいた点（わかりにくい設問、足りない設問、画面の使いにくさ）をまとめて、設問マスタ・質問セットで直す
